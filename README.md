# SPEEDLAB // MISSION CONTROL 🚀

A premium, high-performance web application for typing speed diagnostics and network analysis. Designed with a sleek, glassmorphic "Mission Control" aesthetic, SPEEDLAB provides a professional-grade environment for testing your productivity tools.

### 🔗 [LIVE DEMO](https://zaini12121.github.io/Speed-Lab/)

![SpeedLab Preview](https://via.placeholder.com/1200x600/050a0a/00dbe7?text=SPEEDLAB+MISSION+CONTROL)

## ✨ Features

### ⌨️ Advanced Typing Test
- **Multiple Modes**: Choose between Time, Words, Quote, or Custom text.
- **Real-time Analytics**: Monitor WPM, Raw WPM, Accuracy, and Consistency as you type.
- **Dynamic Text Generation**: Adaptive word banks with optional punctuation and numbers.
- **Session History**: Detailed logs of your typing performance over time.
- **Live WPM Chart**: Visual representation of your speed throughout the session.

### 🌐 Network Diagnostics
- **Phase-based Analysis**: High-precision testing for Latency (Ping), Download Speed, and Upload Speed.
- **Visual Progress**: Cyber-style circular progress indicators.
- **Status Monitoring**: Real-time system status indicators.

### 🎨 Premium UI/UX
- **Iconic Sidebar**: Permanent, slim navigation bar for quick access to all tools.
- **Glassmorphism**: Modern, blurred surface effects for a premium feel.
- **Responsive Design**: Optimized for various screen sizes (best viewed on desktop).
- **Customization**: Adjustable font sizes, sound effects, and caret styles.

## 🛠️ Built With
- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom design system with modern properties.
- **JavaScript (ES6+)**: Core logic and dynamic interactions.
- **Tailwind CSS**: Utility-first styling for layout components.
- **Material Symbols**: Google's modern icon system.
